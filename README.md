## 🧭 How I build

- **Native first**: SwiftUI, Metal and Apple's own frameworks, few dependencies.
- **Tested for real**: nothing is called "working" until it runs on a real device.
- **Private by design**: passwords never handled, secrets kept in the Keychain, data stays on the device.
